# Typefaces

Barlow and IBM Plex Mono (latin + latin-ext, woff2), both under the SIL Open Font
License (see the OFL files here). They are served from this folder, so the dashboard
never contacts an outside service.

Headings ask for Barlow Semi Condensed first and fall back to Barlow. To add it, put
barlow-semi-condensed-500.woff2 and barlow-semi-condensed-600.woff2 here and add their
@font-face rules at the top of css/style.css.
